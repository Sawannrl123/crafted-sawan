# [True Balance](https://www.truebalance.io/)

At **True Balance (Balance Hero)**, I have spearheaded the end-to-end frontend architecture and development of several mission-critical web modules such as **KYC onboarding**, **Lending Insights Partner (LIP) integration**, **lead generation**, and the **Account Aggregator journey**—all seamlessly embedded across both iOS and Android ecosystems.

Leveraging my deep expertise in React, Next.js, and scalable state management, I engineered cross-platform, modular web solutions that empowered the product team to ship new features rapidly—bypassing the need for frequent app store approvals. My work led directly to a **50%+ increase in loan disbursals**, by enabling flexible, data-driven, and robust user flows that adapt to ever-changing compliance and business requirements.

I single-handedly established the engineering patterns for a future-ready, type-safe codebase with best practices in CI/CD, ensured accessibility and SEO compliance, and drove performance optimizations using advanced tools (Cypress, Sentry, Whatap, Kibana, and more). My efforts also included implementing a dynamic design system with reusable UI components in Figma and Storybook, establishing test automation from day one, and instituting monitoring and analytics infrastructure for real-time insights and incident response. By collaborating closely with backend, product, and business stakeholders, I consistently delivered scalable frontend solutions that improved user experience, enhanced stability, and accelerated product rollout—all while being solely responsible for the India region’s requirements and providing technical mentorship to a growing engineering team.

In addition to performance, I implemented robust **monitoring and alerting infrastructure** using **Sentry**, **Kibana**, **Tabalu**, and **GA**, enabling fast detection and resolution of production issues. I also contributed to **securing the frontend stack**, adopted **type-safe development with TypeScript**, and introduced **best practices for CI/CD, accessibility, and SEO**.

As a lead engineer, I managed a **2-member team**, driving key initiatives, conducting regular 1-on-1s, aligning career goals, and fostering a collaborative environment with weekly retrospectives and async demos.

## Work Highlights

- **Modularized Codebase:** Refactored multiple web modules (KYC, LIP integration, lead generation, Account Aggregator) for modularity and reusability, increasing code efficiency and maintainability.
- **Custom Design System:** Created and implemented a reusable UI component library from scratch using Figma and Storybook, boosting design consistency and developer velocity across projects.
- **Performance Improvements:** Reduced bundle size and improved initial load by applying route-level code splitting, dependency analysis, and implementing modern caching strategies; decreased API load while scaling user traffic.
- **Frontend-State Engineering:** Architected scalable, cross-platform state management solutions using React and Zustand, enabling rapid product iterations and seamless embedding in mobile apps.
- **Lighthouse & Web Vitals Optimization:** Drove frontend performance, accessibility, and SEO improvements, lifting Lighthouse/web vitals score and overall user experience.
- **Type-Safe Migration:** Led the migration to a type-safe codebase with TypeScript, improving reliability, bug reduction, and onboarding for new engineers.
- **UI/UX Modernization:** Standardized styling with TailwindCSS, Shadcn, and improved UI accessibility to meet evolving compliance requirements.
- **Automated Testing & Monitoring:** Established Cypress/Jest/RTL test automation and integrated Sentry, Kibana, Tabalu, and Google Analytics for real-time monitoring and rapid incident response.
- **Security & Compliance:** Instituted frontend security best practices, including secure headers, CSP, and robust input sanitization.
- **Scalable DevOps Architecture:** Set up CI/CD pipelines with Docker and Kubernetes, automating deployment with Jira/Github workflows and optimizing for faster releases.
- **Business Enablement:** Enabled business agility by designing flexible, configurable user journeys that respond to dynamic compliance and partner needs—driving a 50%+ increase in loan disbursals.
- **Mentorship & Team Growth:** Managed, mentored, and upskilled a 2-member engineering team, fostering a collaborative culture with regular feedback cycles and continuous improvement rituals.
